# 功能说明

## 服务发现与所有权

默认读取 DSH Host 的 `ctx.loader.entries()`，使用 DSH 已合并的配置树及其实际枚举的 include 子树，不解析磁盘 YAML，也不假定当前 profile 名称。

`mcp_catalog` 显示 Host 树内官方 `@deepseek-ai/dsh-mcp-client` 条目的接管状态。只有自身明确设置 `disabled: true` 的 stdio 条目可按需管理：这是保留连接定义、关闭官方常驻客户端的约定。条件式停用、停用父级、启用中的官方客户端和非 stdio 条目不接管。运行中的同名官方客户端优先，本插件不再为它启动进程。

未挂载预设的定义及自定义 MCP 插件不扫描或提升到 Host 全局作用域。预设中可能存在不同权限或不同凭据，不能仅按服务名自动合并到全部会话。

原生配置表达式使用条目自身的 `entry.evaluate()`，递归求值参数中的 `__jsExpr` 节点。错误时保留上一版有效定义，重载诊断不输出表达式或配置值。

原生发现默认不要求单独的连接文件。手动 `servers` / `serversFile` 模式默认关闭原生扫描；显式组合来源时禁止重复服务名。手动来源不得重复配置仍在运行的官方客户端。`excludedServers` 可以禁止原生服务进入可加载列表。

## 工具、租约与连接池

管理工具为 `mcp_catalog`、`mcp_load`、`mcp_refresh`。目录查询不启动 MCP；加载为调用方 Agent 注册工具；刷新只借用连接发现元数据，不授予原生工具。原生工具从下一模型步骤开始可见。

每个 Agent 的每个服务拥有独立租约和工具注册。默认 `shared` 模式按服务名共享同一 Host 中的进程，`session` 模式按 Agent 创建独立进程。默认共享模式也共享服务端状态和认证。工具授权隔离不是后端状态隔离，也不是操作系统沙箱。

共享池持有会话租约引用、临时扫描引用及业务调用计数。一个 Agent 卸载不关闭其他 Agent 仍使用的连接；最后引用和在途调用结束后立即关闭。并发冷加载合并初始化，等待者取消不传播给其他调用方。

## 配置变化和退役

配置重读串行提交，避免较早快照在较晚快照之后覆盖当前状态。入口不使用文件大小和修改时间作为唯一判断，因此同长度改写或保留时间戳的更新也会被解析。

原生模式监听 `loader/config-update`、`loader/partial-dispose` 和启动 `ready`；管理工具与原生工具入口也重读。事件只反映已由 DSH 应用到配置树的变化，不支持热应用的部署需要重启。

定义改变、条目删除或重新启用官方客户端后，旧池及租约标记 `stale`。已经提交的 RPC 可完成；旧租约不能提交新的请求或重试。空闲边界注销注册，最后引用结束后关闭本插件的进程。退役发现结果不会回填删除后的元数据。

删除全部服务、初始空目录均合法。配置损坏或无法读取时，保留上一版有效配置并返回不包含原始值的警告。原生条目移除会清除对应元数据。停用官方客户端是接管约定；要真正从按需目录移除服务，应删除定义或配置 `excludedServers`。

## 轮次和回收

默认阈值 20，为每个租约累计连续未使用的完成轮次。有效的 `turn/end` 去重；本轮调用过 MCP 则归零。达到阈值时若 Agent、调用或加载仍活跃，则等待安全边界回收。

优先级：服务 `inactiveTurnsThreshold`、JSON 顶层值、管理器配置、默认 20。JSON 重载时可动态修改；管理器配置修改由 DSH 自己的配置生命周期应用。`idleTimeoutMs` 和 `serviceIdleTimeoutMs` 已拒绝，时间经过本身不回收。

归档快照事件、Agent 销毁、显式卸载及插件停用也会释放引用。管理器停用会统一清理它的全部资源；不承诺等待所有外部业务效果完成，也不会撤销已提交请求产生的实际业务结果。

## 进程、传输和结果

当前只实现 stdio 换行 JSON-RPC，初始化协议默认 `2025-06-18`。支持工具发现分页，上限 100 页；重复游标拒绝；输入缓冲上限 16 MiB。服务主动 `ping` 可响应，其他主动请求返回不支持，工具变更通知没有自动同步实现。

只读发现最多两次尝试。工具调用仅在只读声明或 `readOnlyTools` 命中时，对匹配的暂时错误最多尝试三次；写调用不重试。只读标记由配置和服务提供，插件不验证真实副作用。

文本、嵌入资源文本和结构化结果会输出，非文本内容以省略提示代替。结果默认截断到 60000 字符。子进程 stderr 被读取但丢弃，不把可能带凭据的输出原样记录。

服务继承 Host 环境再合并连接 `env`。`serversFile`、`cacheFile`、`cwd` 支持 `~` 展开；命令和参数不做 shell 或环境变量插值。

macOS 下用独立进程组启动，在终止时发送 `SIGTERM`，约两秒后 `SIGKILL` 兜底。主动脱离进程组的后台守护进程不受该组信号控制。Linux 未独立验收，Windows 不支持发布。

## 缓存和待验收范围

缓存仅存服务信息、工具名、描述摘要和更新时间，不保存凭据、请求参数或结果。工具描述自身可能含敏感信息，不应在服务元数据中存放秘密。不同 Host 可以指定不同缓存文件，跨进程缓存写入协调未实现。

测试覆盖真实 DSH 注册表与 Loader 和本地假服务。真实有状态 MCP 的跨会话业务、未挂载预设的统一发现、自然语言自主触发可靠性、完整恢复/fork业务及同进程热升级尚需独立验收。先前文档将单一 YAML 扫描描述为全量原生发现，该说法已撤回并由当前实现和测试替代。
